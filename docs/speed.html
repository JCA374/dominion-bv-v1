Speed

Machine: 8 cores (laptop), 7 GB RAM, no usable GPU (integrated graphics). Everything that costs time is C: the engine and RL-v3's network, run at batch size 1 inside rollouts.

  • Plain c2 vs c2 game: ~0.05–0.3 s.
  • One rollout from a buy to the end of the game: ~5 ms per core (about 200 per second per core).
  • Teacher game (every buy graded, adaptive 16→64 draws): ~97 s. With 16→32 draws: ~35 s.
  • Labels: one position costs about 6 candidates × 16–32 rollouts ≈ 0.5–1 s per core. Measured rates are on the Training tab (states_per_s).
  • Student: 50k parameters, one pass per buy in C (microseconds). Training on 100k positions takes a few minutes on CPU.
A GPU would not help: the cost is many small sequential game simulations, not big matrix products. More CPU cores would.
