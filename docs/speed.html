4. Exactness

The fast net is used for decisions only, and the gate checks decisions. On 1,000 games of c2 vs c2 (one per kingdom), 100% of games came out identical (winners, scores, turns) with the fast agent everywhere (results/fast_equivalence.json). The label checksum of the benchmark games was also unchanged.

Why not a GPU?

Each decision is one position (batch 1) inside a game that must finish before the next decision is known. That work is serial and latency-bound, so a GPU's thousands of lanes would sit idle. More CPU cores would help almost linearly.
