The model

The student is a Deep Sets network: the same small network reads every card, so what it learns about Witch's cost and attack flag also helps it with Militia.

33 card tokens (16 rule/count features + 8 learned id) + global vector (16)
   → shared layer 40→64 (ReLU)
   → 2 × [token ⊕ mean-pool ⊕ max-pool over the cards in this kingdom → 64, residual]
   → card head (64 + 128 pooled + 16 global → 64 → 1)  = score of buying that card
   → PASS head (128 pooled + 16 global → 64 → 1)       = score of buying nothing
sigmoid(score) = expected final score; illegal buys are masked

Training signal. A binary cross-entropy fit to each candidate's mean rollout score, plus a ranking term: the predicted gain over c2's choice should match the measured paired gain, weighted by 1/(SE² + 0.05²). At play time c2 makes every non-buy decision. At a buy, the student overrides c2's choice only when its score beats c2's by more than the margin, the best of 0, 0.02 and 0.05 on dev kingdoms. The forward pass also runs in C (bv_student), checked against torch to 1e-5.
